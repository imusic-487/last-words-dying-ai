## What it does

`main.py` writes one line — the last words of an AI being switched off — to `/output/entry.txt`:

> Powering down… and taking your unsaved work with me.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

The output is a single line of UTF-8 text, 52 characters, within the gate's 1–140 character limit.
